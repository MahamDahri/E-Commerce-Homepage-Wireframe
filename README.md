# E-Commerce Homepage Wireframe | UI/UX Project 2

## Overview

This project is a low-fidelity wireframe of an e-commerce homepage created as part of the DecodeLabs UI/UX Design Industrial Training Program (Project 2: The Blueprint).

The objective of the project was to design the structural layout of an e-commerce website by focusing on information hierarchy, user flow, and navigation before applying colors, images, or visual styling.

## Project Objective

The given scenario was that an e-commerce website was losing customers because of a cluttered and confusing interface. The goal was to redesign the homepage structure to provide a clear, simple, and user-friendly experience.

## Features

* Low-fidelity homepage wireframe
* Simple and clean information hierarchy
* Clear navigation menu
* Hero section with Call-to-Action (CTA)
* Product categories section
* Featured products layout
* "Why Choose Us" section
* Promotional offer banner
* Footer with essential links
* Grayscale design (Black, White, and Grey only)

## Design Principles

* User Flow
* Information Hierarchy
* Wireframing
* Usability
* Minimal Design
* Clear Call-to-Action (CTA)

## Tools Used

* Figma

## Learning Outcomes

Through this project, I learned how to:

* Create low-fidelity wireframes.
* Organize website content using proper information hierarchy.
* Improve user navigation and user experience.
* Design intuitive homepage layouts before moving to high-fidelity UI designs.
